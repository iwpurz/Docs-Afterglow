# Privacy

Docs Afterglow does not collect, transmit or share any data.

- It runs only on `docs.google.com/document/*` and changes how the page looks. It does not read, store or
  send the content of your documents.
- Your settings, saved themes and any images/videos you add are stored locally with Firefox's extension
  storage and never leave your device. Removing the extension deletes them.
- It makes no network requests of its own. If you enter an image URL as a background, Firefox fetches that
  image the way it would any web image.
- No analytics, telemetry, ads or third-party code.
- Exported theme/settings files contain only what you see in the app. Theme files you import are
  sanitized: only embedded images and videos are kept, and remote links are ignored.
